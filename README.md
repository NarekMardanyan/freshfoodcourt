# Fresh Food Court

Одностраничный сайт заведения (шаурма и фастфуд) на трёх языках: English / Русский / Հայերեն.
Чистый HTML + CSS + JS, без сборки — достаточно открыть `index.html` или выложить папку на любой хостинг (GitHub Pages, Netlify и т.д.).

## Что где менять

| Что | Где |
|---|---|
| Телефон, WhatsApp, Telegram, Instagram, адрес, координаты карты | `js/config.js` → `contacts` |
| Часы работы | `js/config.js` → `hours` |
| Условия доставки (мин. заказ, стоимость, время) | `js/config.js` → `delivery` |
| Категории и блюда (названия, описания, цены в драмах) | `js/config.js` → `categories`, `menu` |
| Акции | `js/config.js` → `promos` |
| Тексты интерфейса (кнопки, заголовки) | `js/i18n.js` |
| Цвета и стиль | `css/style.css` → `:root` |

## Фото

Положите файлы по путям, указанным в `js/config.js` (например `images/menu/shawarma-chicken.jpg`).
Фото главного экрана — `images/hero.jpg` (лучше квадратное, еда на светлом фоне).
Пока файла нет, показывается цветная заглушка с эмодзи — ничего не ломается.

Рекомендуемые размеры: меню — 800×600 (4:3), акции — 1200×675 (16:9), JPG/WebP до ~200 КБ.

## Язык

Язык выбирается переключателем в шапке, запоминается в браузере, а при первом визите определяется по языку браузера.
Можно дать прямую ссылку: `?lang=en`, `?lang=ru`, `?lang=hy`.
